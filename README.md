# Global Superstore SQL Data Analysis 

A **MySQL-based data analysis project** using the Global Superstore dataset to analyze sales, profit, products, customers, regions, discounts, and shipping performance.

##  Project Overview

| Metric           |     Value |
| ---------------- | --------: |
| Records Analyzed |    48,361 |
| Analysis Period  | 2011–2014 |
| Total Sales      |    $7.81M |
| Total Profit     |     $711K |
| Tool             |     MySQL |

##  Analysis Areas

* Sales & Profit Analysis
* Product & Category Performance
* Customer Analysis
* Regional & Market Analysis
* Discount Impact on Profitability
* Shipping Mode Analysis
* Yearly Sales & Profit Trends
* Year-over-Year Sales Growth
* Loss-Making Product Analysis

##  SQL Skills Used

`SELECT` · `WHERE` · `GROUP BY` · `HAVING` · `ORDER BY` · `SUM()` · `AVG()` · `COUNT()` · `DISTINCT` · **CTE** · **Window Functions** · `LAG()`

##  Key Insights

* **Office Supplies** generated the highest sales and profit.
* Sales grew by approximately **93% from 2011 to 2014**.
* YoY sales growth reached **26.67% in 2014**.
* **Central** was the leading region by sales.
* High discounts of **0.80–0.85** were associated with negative margins.
* **12,045** records were loss-making.
* **Standard Class** was the dominant shipping mode.
